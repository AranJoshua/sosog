Maragsa font (installed)

Files in this folder:
  Maragsa.woff2          the font the website loads (the creator's own web version)
  Maragsa-LICENSE.txt    the creator's license note that came with the download
  maragsa.css            tells the browser where the font is; every page loads it

Notes
- Only the WOFF2 is kept here. The full OTF desktop file is deliberately not committed, because
  this repository is public.
- The license note says "free font license, for one (1) user" and points to the creator's EULA at
  https://jadmaza.gumroad.com/p/eula-free . Read the EULA's web-use terms. If anything is unclear, ask
  the creator (jadmaza.com) before launch.
- To replace the font later, drop a new file here named Maragsa.woff2 (the only format maragsa.css and the page preload point to).
